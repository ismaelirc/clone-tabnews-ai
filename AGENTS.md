# AGENTS.md

Clone do TabNews feito com Next.js (App Router, `app/`), JavaScript puro e npm.

- A interface é em português do Brasil (`pt-BR`).
- Use o App Router, não o Pages Router.
- O Next.js traz a documentação da versão instalada em `node_modules/next/dist/docs/`. Consulte-a antes de usar APIs que possam ter mudado em relação a versões antigas.
